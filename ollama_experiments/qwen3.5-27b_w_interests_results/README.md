# qwen3.5:27b 实验结果(2026-07-31)

在 DGX Ollama 服务(`http://10.236.129.210:11434`)上,用 `qwen3.5:27b`(qwen3.5:9b 的更大版本)跑了一次 `sequential` + `w_interests`(原论文标准设置),personas 用仓库自带的 `text-files/us_50_gpt4o_w_interests.json`(50人),n=3(seed 0/1/2),和之前 `qwen3.5:9b`/`gemma4:e4b`/`mistral-small3.2:24b` 的对比样本量一致。

沿用了 `qwen3.5:9b` 实验时修好的 `/api/chat` 原生接口调用方式(`think: false` 完全关闭思考链),单次真实规模请求约 10-15 秒,3 个网络(150 次调用)总耗时约 20 分钟,50/50 次调用全部一次成功解析。

## 结论

- **核心发现不仅复现,而且被放大了**:political affiliation 依然是唯一一个明显比 GPT-3.5 更极端的维度,且 `qwen3.5:27b` 比更小的 `qwen3.5:9b` **更极端**——cross_ratio 从 0.115 降到 0.021(仅为 GPT-3.5 的约 1/14),same_ratio 从 1.919 升到 2.016。换句话说,3个网络里 27b 生成的政治同质网络几乎是"清一色同党派抱团"。
- 其余四个维度(age/gender/race/religion)上,27b 和 9b 表现相近,都比 GPT-3.5 更接近随机基线(same_ratio 更接近1.0),说明"放大偏差"这件事在 qwen 系列里似乎是政治维度特有的,不随模型变大而扩散到其他人口统计维度。
- **这次结果说明"换更大的模型"并不能缓解政治同质性被高估的问题,反而在这次 n=3 的样本里更严重了**。样本量小(qwen3.5:27b 和 9b 都只有 n=3,而 GPT-3.5 是原论文的 n=30),结论置信度有限,值得增加 seed 数量做进一步验证。
- 结构性指标(density、聚类系数)在 27b 和 9b 之间接近,而且标准差比 9b 更小(比如 density 0.356±0.004 vs 0.387±0.024),27b 的网络结构在3次运行之间更稳定一致。
